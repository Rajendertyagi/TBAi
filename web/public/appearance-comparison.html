Appearance

Theme, typography, and display preferences. Applied instantly and remembered on this device.

Theme

Light or dark interface, and the colour theme used in each.

Color theme
Switches the whole app between light and dark tokens.

Colour theme for light mode

Typography

Independent controls for interface, code, terminal and reading typography, plus application scaling.

Interface Typography

Fonts and weights applied across navigation, messages, dialogs, and controls. Compact metadata scales with the interface size and never drops below 9px.

Interface font
Primary font family applied across chat messages, buttons, and navigation.
Interface font size
Actual font size for interface text (16px). Standard is 16px; the minimum is 14px. Does not scale layout or spacing.
px
Interface font weight
Body text weight for interface elements.

Code Block Typography

Monospace fonts, weights, and sizing for code blocks, diffs, and code previews.

Code font
Monospace font family used for syntax-highlighted code blocks, diffs, and code previews.
Code font size
Independent size for code blocks and diffs (13px). Standard is 13px.
px
Code font weight
Weight applied to syntax highlighting and code blocks.
Code word wrap
Wrap long lines in code blocks instead of scrolling horizontally. Visual only — copied code is unchanged. Diffs never wrap.

Terminal Typography

Fonts, weights, and sizing for captured command output (run_command, OpenCode bash/shell), including exit and timeout lines.

Terminal font
Monospace font family used for captured terminal output, including exit and timeout lines.
Terminal font size
Independent size for terminal output, including exit and timeout lines (12px). Standard is 12px.
px
Terminal font weight
Weight applied to terminal output, including exit and timeout lines.
Terminal output wrapping
Wrap long lines in terminal output, preserving whitespace and indentation. Visual only — output content is unchanged.

Reading Typography

Line spacing for readable prose — markdown paragraphs, list items, and reasoning.

Reading line height
Vertical paragraph line spacing for chat transcripts, markdown content, and reasoning.

Application Scale

Scales the whole interface — navigation, cards, buttons, icons, spacing, and panels.

Application scale
Scales the entire interface (100%). 100% is default. Font preferences are unchanged.
