2. OpenCode Architecture Boundary

TBAi isolates OpenCode strictly inside src/services/opencode/ (backend) and web/src/features/opencode/ (frontend).

OpenCode communicates over a managed child process (CLI server) and local native V2 SSE client—never leaking into Direct API chat routes.

3. Lead Planner & User Execution

Lead Architect audits code → updates ledger → generates prompt drawer. User copies prompt into external coding app → reports test results.
